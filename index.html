1. The Suicide-Burn Quadratic Solution

          

            To stop exactly at altitude $0$, the flight computer equates kinetic energy to the work done by deceleration:
          

          

            a_decel = (T_thrust / mass) - g;

            h_burn = (vy * vy) / (2 * a_decel);

            if (altitude <= h_burn) ignite();
          

        


        

          
2. Two-Stage Boundary Calculus Integration

          

            Acceleration $a(t)$ is integrated to update velocity $v(t) + C_1$, which is integrated again to update altitude $h(t) + C_2$:
          

          

            v_y += a_y * dt; // ∫ f''(t) dt

            altitude += v_y * dt; // ∫ f'(t) dt
